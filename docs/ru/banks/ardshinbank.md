# Ardshinbank

## Поддерживаемые форматы

### [FULL] XLSX из email — рекомендуется

Ardshinbank присылает `.xlsx` по email ежемесячно или ежегодно. В файле три листа (английский, русский, армянский); приложение использует **армянский** лист — в нём больше деталей.

- Номера счетов контрагентов, похоже, только внутренние Ardshinbank — это ограничивает отслеживание переводов с других банков.
- Поддерживает все функции приложения и отчёты Beancount.
- Настройка в `config.yaml`: `ardshinbankXlsxFilesGlob`
- Парсер: `ardshin_xlsx_parser.go`

### [NONE] XLSX с сайта

Файлы с https://ardshinbank.am/ — **не поддерживаются** (те же, что из email, или с меньшим объёмом данных).

## Ручное скачивание

1. Сохраните XLSX-выписку из email Ardshinbank
2. Положите файл рядом с исполняемым файлом приложения (по шаблону `ardshinbankXlsxFilesGlob`)

## Скачивание в приложении

Недоступно для Ardshinbank.

## Скачивание через CLI

Недоступно для Ardshinbank.
