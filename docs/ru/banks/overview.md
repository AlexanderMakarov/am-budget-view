# Обзор поддерживаемых банков

Поддерживаемые источники:

- Счета [Inecobank](inecobank.md)
- Бизнес-счета [AmeriaBank](ameria-business.md)
- Личные счета [MyAmeria](myameria.md)
- Личные счета [Ardshinbank](ardshinbank.md)
- Счета [ACBA](acba.md)
- [Generic](generic.md) CSV-файлы с ручным/пользовательским маппингом

Банки обычно присылают выписки/транзакции по email ежемесячно или ежегодно и позволяют скачивать списки транзакций на своих сайтах.

**Важно:** файлы из email обычно менее пригодны (кроме Ardshinbank), так как могут быть защищены паролем или не содержать номеров счетов получателя/отправителя. Это усложняет анализ:

1. Сложно автоматически обрабатывать защиту паролем.
2. Категоризация по счетам не работает.
3. Переводы между своими счетами не определяются и учитываются как «прочие доходы/расходы», искажая статистику.
4. Отчёты Beancount построить нельзя.

## Скачивание файлов в приложении

Для **MyAmeria** и **AmeriaBank (бизнес)** проще всего использовать страницу [Файлы](/files):

1. **Настройки скачивания** — сохраните Client ID, дату начала и папку в `config.yaml` (без секретов).
2. **Скачать сейчас** — вставьте свежий токен **Authorization** (MyAmeria) или **Cookie** (Ameria Business) из DevTools браузера. Учётные данные используются один раз и **не сохраняются**.
3. В документации по банкам описано, как копировать значения из DevTools — ссылки есть в строке источника и в окне скачивания.

Другие банки: скачайте файлы вручную с сайта банка и положите рядом с приложением (см. страницы ниже).

## Где найти инструкции

- **В приложении:** [Файлы](/files) → **Настройки скачивания** / **Скачать сейчас**, ссылки на `/docs/bank/{sourceId}` у каждого источника.
- **В репозитории:** `docs/en/banks/` (английский) и `docs/ru/banks/` (русский).
- **Автоматизация:** [MyAmeria](myameria.md) и [AmeriaBank бизнес](ameria-business.md) — сначала UI, затем ручное скачивание с сайта, затем опционально CLI.

Чтобы добавить поддержку нового банка, [создайте issue](https://github.com/AlexanderMakarov/am-budget-view/issues) с примером файла транзакций и инструкцией, как вы его получили. Файл может быть отредактирован для скрытия личных данных, но должен сохранить формат, длину и набор символов оригинала.
