# ACBA

## Поддерживаемые форматы

### [PARTIAL] XLS из ACBA Digital

Скачивайте из [ACBA Digital](https://acbadigital.am/dashboard). См. также `docsdata/ACBA/ACBA get transactions.md` со скриншотами.

1. Выберите счёт или карту → **Transactions**
2. Укажите период, язык **армянский**, формат **Excel**
3. Нажмите **Download**

Выписки на армянском содержат больше информации, чем на английском. Выписки по счетам информативнее, чем по картам.

Так как только часть транзакций (только по обычным счетам) содержит номера счетов получателя/отправителя:

- Отчёты Beancount построить нельзя (приложение покажет предупреждение в терминале)
- Категоризация по счетам работает не для всех транзакций

- Настройки в `config.yaml`: `acbaRegularAccountXlsFilesGlob`, `acbaCardXlsFilesGlob`
- Парсеры: `acba_xls_stmt_regular_account_parser.go`, `acba_xls_stmt_card_parser.go`

**Совет:** не запрашивайте выписки по email — файлы защищены паролем.

## Ручное скачивание

1. Войдите на https://acbadigital.am/dashboard
2. Счёт/карта → Transactions → настройте экспорт (армянский, Excel, период)
3. Скачайте и положите файлы рядом с приложением
