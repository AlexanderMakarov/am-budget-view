# Generic CSV

## Поддерживаемые форматы

### [FULL] Generic CSV

CSV-файлы с транзакциями из любого источника.

- Настройка в `config.yaml`: `genericCsvFilesGlob`
- Парсер: `generic_csv_parser.go`
- Поддерживает все функции приложения и отчёты Beancount
- Номер и валюта счёта определяются из полей ниже

**Обязательные заголовки** (первая строка):

| Заголовок | Описание |
|-----------|----------|
| `Date` | Дата транзакции в формате `YYYY-MM-DD` |
| `FromAccount` | Номер счёта отправителя |
| `ToAccount` | Номер счёта получателя |
| `IsExpense` | `true` для расхода (`FromAccount` — ваш), `false` для дохода (`ToAccount` — ваш) |
| `Amount` | Сумма в валюте счёта, точка и 2 знака (например, `1500.30`) |
| `Details` | Описание транзакции (основной источник категоризации) |
| `AccountCurrency` | 3-буквенный ISO-код валюты |
| `OriginCurrency` | *(необязательно)* Исходная валюта до конвертации |
| `OriginCurrencyAmount` | *(необязательно)* Сумма в исходной валюте |

CLI-скачивание MyAmeria (`make bank-downloader`) также создаёт Generic CSV.

## Ручное скачивание

Создайте или экспортируйте CSV с указанными заголовками и положите рядом с приложением (по шаблону `genericCsvFilesGlob`).

## Скачивание в приложении

Не применимо — Generic CSV это пользовательский/ручной формат.

## Скачивание через CLI

Полуавтоматическое скачивание MyAmeria через `make bank-downloader` выдаёт Generic CSV (см. [документацию MyAmeria](myameria.md)).
